# Hanare

[English](README.md)

メニューバーのアイコンを隠すアプリです。

Hanare は弓道の「離れ」です。メニューバーに立つ袴姿の射手が、使わないアイコンを隠します。射手にカーソルを乗せると「会」の姿勢になり、クリックすると「離れ」とともに隠していたアイコンが順に現れます。隠すアイコンは設定か、ドラッグで選びます。設定で選んだアイコンも、カーソルを動かさずに射手の左隣へ自動で移動するので、隠れるアイコンは常に射手の左側に並びます。「すべてのアプリ」で全アプリをまとめて選べます。

## 動作環境

- macOS 27 Golden Gate 以降（Apple シリコン）

## インストール

### Homebrew

```sh
brew install --cask ohsawa0515/tap/hanare
```

### 手動

[Releases](https://github.com/ohsawa0515/hanare/releases) から `Hanare-<version>.zip` をダウンロードして展開し、`Hanare.app` を `/Applications` に移動します。

### 初回起動

Hanare は公証を受けていないため、初回起動時に macOS にブロックされます。システム設定 > プライバシーとセキュリティ を開き、「このまま開く」をクリックしてください。

初回の起動時に、macOS が保護している2つのファイル（メニューバーに表示するアプリの一覧と、メニューバーの並び順）へのアクセスを求めます。開いた画面で、それぞれのファイルを選んでください。Hanare が使えるのは選んだ2つのファイルだけで、フルディスクアクセスは不要です。後から設定画面で許可することもできます。任意で、システム設定 > プライバシーとセキュリティ > アクセシビリティ も許可すると、Command+ドラッグでアイコンを選べるようになります（下記）。

起動時には、射手の左にあるアイコンが隠れます。並べたメニューバーの配置がそのまま反映されます。

## 使い方

| 操作 | 結果 |
| --- | --- |
| 射手をクリック | 選んだアイコンを隠す / 表示する |
| アイコンを Command+ドラッグで射手の左へ移動 | そのアイコンが隠れる（アクセシビリティが必要） |
| 表示中のアイコンを Command+ドラッグで射手の右へ移動 | そのアイコンを隠さなくなる（アクセシビリティが必要） |
| 射手を右クリック | メニュー（すべてのアイコンを表示、設定、終了） |

隠すアイコンは設定で選びます。システムの欄に Wi-Fi、サウンド、バッテリー、ディスプレイ、Bluetooth、再生中、入力メニューが、アプリの欄にメニューバーのアイコンを持つすべてのアプリが並びます。

設定では、キャラクター（男性の射手、女性の射手、シンプルな矢印）、自動で隠すまでの時間、ログイン時の起動を選べます。

## 仕組み

macOS 27 ではメニューバーをシステムが1枚のウィンドウとして描くため、これまでのメニューバー管理アプリの方法は使えなくなりました。Hanare は、システム設定 > メニューバー と同じ設定を使ってアイコンの表示をオンオフします。変更はシステムにすぐ反映されます。アイコンの位置は、システムが保存しているメニューバーの並び順から読み取り、アイコンの移動もこの並び順を書き換えて行います。

- アイコンはアプリ単位で隠れます。複数のアイコンを出すアプリは、まとめて隠れます。
- マイクとカメラの使用中を示すアイコンと時計は隠せません。
- Hanare が隠したものだけを元に戻します。システム設定でオフにしたアイコンはオフのままです。
- 隠したアイコンは Hanare の終了時に戻ります。異常終了した場合は、次の起動時に戻ります。メニューの「すべてのアイコンを表示」でいつでも戻せます。
- 非公開のシステム設定を使っているため、今後の macOS の更新で動かなくなる可能性があります。

## ビルド

```sh
swift build        # デバッグビルド
swift test         # ユニットテスト
swift run Hanare   # パッケージせずに実行
./scripts/build-app.sh  # dist/Hanare.app と dist/Hanare-<version>.zip を作成
```

Xcode 27 以降が必要です。
